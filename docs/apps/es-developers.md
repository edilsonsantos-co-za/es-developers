# ES Developers

ES Developers is this site: the public documentation for the ES apps, live at
**[developers.edilsonsantos.co.za](https://developers.edilsonsantos.co.za/)**.

**Source:** [edilsonsantos-co-za/es-developers](https://github.com/edilsonsantos-co-za/es-developers) (repository access may be required).

## Stack

- Docusaurus 3, built with Node.js 22.
- Static output served by Nginx in a Docker image.
- An autogenerated sidebar that follows the `docs/` folder.

Pages are written for the public. Internal workspace notes, credentials and private journal content are never
copied here.

## Contributing

```bash
npm ci
npm run start   # live reload
npm run build   # production build; fails on broken internal links
```

See [Publishing and releases](../guides/publishing-and-releases) for how the site is deployed.
