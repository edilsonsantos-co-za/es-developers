# ES Labs

ES Labs is a workspace for experiments, prototypes and hackathon work. An experiment is not necessarily
maintained, supported, secure for production use, or available as a public service. Projects that mature should
receive their own ownership, support, security and release review before being treated as an ES app.

**Source:** [edilsonsantos-co-za/es-labs](https://github.com/edilsonsantos-co-za/es-labs) (repository access may be required).

The source repository contains work in different stages. This public page deliberately avoids publishing local
service URLs, account details, unfinished product claims or private automation instructions.
