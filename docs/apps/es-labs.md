# ES Labs

ES Labs is where design and UI ideas for the ES apps are tried before they ship: bento cards, logos, theme packs,
dashboards, navigation bars, error pages and cover images. Each experiment is a static page; the chosen variant is
then copied into the app that uses it.

Labs is private: the ES apps launcher only shows it to the owner. An experiment is not maintained, supported or
production-ready. Anything unrelated to the ES apps, such as hackathon entries, lives in its own repository, and an
experiment that grows into an app moves into its own repository too.

**Source:** [edilsonsantos-co-za/es-labs](https://github.com/edilsonsantos-co-za/es-labs) (repository access may be required).

The source repository contains work in different stages. This public page deliberately avoids publishing local
service URLs, account details, unfinished product claims or private automation instructions.
